> 用途：产品演示 / 项目汇报 / 培训讲解时可直接照读的口播稿。
> 建议时长：8–12 分钟。每节先用「一句话开场」引入，再展开操作演示。

## 一、开场：这是一个什么样的工具

各位好，今天给大家介绍的是 **便利贴 StickyNote**——一款运行在 Windows 桌面上的轻量级「便利贴 + 任务清单」工具。

它要解决的问题很朴素：**我们每天脑子里都有很多临时想到的事、要记的事、要做的事，但它们不该被塞进复杂的待办软件里，也不该随手写在纸上然后弄丢。** 所以这个小工具做了两件事：

1. **便利贴**：像真实便利贴一样贴在桌面上，随手记录、随手看得到；
2. **任务清单**：把要做的事列出来，勾一下完成，进度一目了然。

整个项目基于 **.NET 10 + WPF** 开发，是一个原生 Windows 桌面应用。它不需要联网、不依赖账号，所有数据都存在你自己的电脑本地，**打开即用、关闭不丢**。

---

## 二、整体设计思路：三类窗口，各司其职

在动手演示之前，先介绍它的整体结构，方便大家理解后面的功能。

应用一共由三类界面组成：

- **便利贴窗口**：贴在桌面上的那张小卡片，负责记录本身；
- **任务清单窗口**：桌面上的待办清单，负责勾选和推进；
- **管理界面（主窗口，标题「我的便利贴」）**：一个集中管理中心，用来查看、搜索、新建、删除所有的便利贴和任务清单。

此外还有两个"随时待命"的角色：

- **系统托盘**：程序常驻在右下角托盘，关闭主窗口只是隐藏，**不会退出程序**；
- **全局设置与默认外观**：分别控制"全局行为"和"新建内容长什么样"。

理解了这个结构，后面的功能就都是挂在它上面的枝叶了。

---

## 三、核心功能一：便利贴

### 1. 一张"懂事"的便签

先看最基础的便利贴。它做成了**无边框、圆角、半透明**的卡片样式，带一点阴影，贴在桌面上不会显得生硬。

- 按住**标题栏拖动**即可移动位置，拖**边缘**可以缩放大小；
- 窗口位置和尺寸会被**自动记住**，下次启动还在原地；
- 它**默认置顶**，不会被其他窗口压住，同时**不占用任务栏**——桌面上永远是清爽的。

### 2. 记录与编辑

便签正文可以直接输入，支持自动换行、回车换行，内容变化会**实时保存**。它还支持 **100 步撤销**，写错了按 `Ctrl+Z` 就能退回去。

### 3. 锁定与"悬停显示"

每张便签标题栏上有几个小按钮，这里重点讲两个：

- **🔒 锁定**：点一下锁定，便签内容就变成只读，防止误删误改。想编辑时再点一下解锁；
- **👁 悬停显示**：开启后，**鼠标移进来才显示，移开就自动隐身**。这对"不想被别人看到"或者"想让桌面更干净"的场景特别有用。隐身时它是**穿透**的，不会挡住你点桌面上的其他东西。

### 4. 每张便签都能单独定制外观

点标题栏的 **⚙ 设置**，会在这张便签旁边弹出它的"外观设置"，可以调：

| 可调项 | 说明 |
| --- | --- |
| 便签标题 | 用于区分多张便签，不填就显示"便利贴" |
| 背景颜色 | 从最近使用的色板里选，也能调出系统取色器自定义 |
| 背景图片 | 可以给便签铺一张图片做背景 |
| 文字颜色 | 正文、标题、按钮颜色统一跟随 |
| 字体大小 | 8–48 号，滑杆调节 |
| 窗口透明度 | 只让**背景**变透明，**文字始终清晰** |

这里有个很重要的设计理念：**每张便签的外观是独立的。** 你改了 A 便签的颜色，B 便签不会跟着变。已创建的内容永远不受"默认样式"改动的影响。

## 四、核心功能二：任务清单

### 1. 勾选式待办

任务清单看起来像一张可以打钩的清单：每条任务前有个复选框，**勾上就代表完成，文字会自动划掉**。

标题栏的 **＋** 按钮可以新增任务。每条任务右侧的行内按钮，还可以：

- **＋ 加子任务**：任务可以一层层嵌套，做出"大任务拆小任务"的结构，最多支持多层；
- **🗑 删除任务**。

### 2. 两个很顺手的键盘操作

为了让大家快速录入，清单里做了三个快捷操作：

- 按 **`Enter`**：提交当前这条，并**新建一条同级任务**；
- 按 **`Tab`**：提交当前这条，并**在它下面新建一条子任务**；
- 按 **`Shift + Enter`**：在任务内换行（不是新建）。

一句话概括：**边想边敲，一条接一条不用碰鼠标。**

### 3. 排序与进度

任务的排列是自动的：**未完成的在上面，已完成的沉到底部；同一区域内，越新加的任务越靠上。** 也就是说新任务永远置顶，符合"先处理最新的"直觉。

在管理界面里，每一张任务清单卡片都会显示 **「已完成 3/8」** 这样的进度，一眼就知道推进到哪了。

### 4. "显示已完成任务"开关（新功能）

做完的任务有时候看着碍眼。为此加了开关：

- 在**任务清单的「默认外观」**里，有一个"显示已完成任务"的选项，决定**新建清单**的初始行为；
- 每张清单自己的 **⚙ 设置**里，也有同一个开关，可以**单独控制这一张清单**是否显示已完成项。

关掉之后，已完成的任务（连同它们的子任务）会从清单里隐藏，界面瞬间清爽。

### 5. 同样支持锁定与悬停显示

和便利贴一致：🔒 锁定后不可编辑（但**仍然可以勾选完成**——因为"完成"是在推进工作，不该被锁住）；👁 悬停显示则让清单只在鼠标移入时才出现。

## 五、核心功能三：管理界面（主窗口）

当便利贴和清单变多之后，就需要一个"总控台"。这就是主窗口——**「我的便利贴」**。

### 1. 左侧导航：两类内容分开管

左边是导航栏，**便利贴** 和 **任务清单** 两个分类，切换时会有一个蓝色指示条高亮当前所在分类。两个分类的内容、搜索、排序、视图**各记各的，互不干扰**——你在便利贴里搜索的"会议"，切到任务清单时不会被带过去。

### 2. 顶部工具栏：搜索、排序、视图、新建

- **搜索框**：便捷贴按标题或正文搜索；任务清单则会**深入每一层子任务**去匹配，大小写不敏感；
- **排序**：可切换「默认 / 标题 A→Z / 标题 Z→A」；
- **视图切换**：**卡片视图**和**列表视图**两种展示方式随你挑；
- **🎨 默认外观**：按当前分类，打开对应的"新建默认样式"设置（下面细讲）；
- **＋ 新建**：按当前分类新建一张便签或一份清单。

### 3. 内容区：双击打开、就地改标题

每张便签 / 清单在管理界面里是一张卡片或一行。这里有几个易用的交互：

- **双击**卡片 → 打开对应的桌面窗口；
- 标题可以**直接在卡片上改**，改完即时同步；
- 卡片上的 **🗑** 可以删除（注意：这里是**真删除**，会从数据和磁盘上移除）。

没有数据时，界面会给出明确的空状态提示，而不是一片空白。

## 六、核心功能四：默认外观（新建的"出厂设置"）

「默认外观」是一个单独的窗口，它管理的是**以后新建**的内容长什么样，入口就在管理界面顶部的 **🎨** 按钮。

关键特点：**便利贴和任务清单是两套完全独立的默认值。**

- 在**便利贴**分类下点开，只能设置便利贴的默认（透明度、字号、背景色、文字色）；
- 在**任务清单**分类下点开，设置的是任务清单的默认，并且**多一个「显示已完成任务」开关**。

举个例子：你可以把便利贴默认设成"黄色、半透明"，把任务清单默认设成"浅蓝、不透明、隐藏已完成项"，二者互不影响。**这个功能只影响新建对象，已经建好的便签和清单一个都不会变**——这正是我们前面反复强调的"独立外观"理念。

## 七、核心功能五：全局设置与桌面集成

点管理界面顶部的 **⚙**，打开全局设置，这里管的是整个程序的行为：

| 设置项 | 作用 |
| --- | --- |
| **开机自启** | 勾选后随 Windows 一起启动，开机就能看到你的便签 |
| **窗口始终置顶** | 统一控制所有便签和清单位置层级 |
| **隐藏/显示全部窗口快捷键** | 录一个全局快捷键，比如 `Ctrl+Alt+H`，一键把所有窗口藏起来或叫出来 |

那个**全局快捷键**值得一提：它通过系统级热键注册实现，**即使程序没有获得焦点也能响应**。录入时点「修改」，直接按下组合键即可（至少包含一个修饰键），按 `Esc` 取消；不想要了就点「删除」。

### 托盘常驻

程序常驻在右下角系统托盘，右键菜单可以：

- 新建便利贴 / 新建任务清单；
- 管理便利贴（打开主界面）；
- **隐藏/显示全部窗口**（菜单文字会随当前状态自动切换）；
- 退出程序。

另外，**双击托盘图标**就能唤出管理界面。**关闭管理窗口不会退出程序**，它只是躲进托盘，继续在后台守着你的便签。

整个应用还是**单实例**的：重复启动不会开出两个程序，而是把已经运行的窗口重新叫到最前面。

## 八、数据：本地、可靠、不怕丢

最后讲一个大家最关心的点——**数据安全**。

所有数据都保存在本机：

```
%LOCALAPPDATA%\StickyNoteWPF\
├── notes.json      # 便利贴与任务清单数据
└── settings.json   # 设置、默认外观、窗口尺寸记忆、最近颜色等
```

程序做了几层保护：

1. **实时保存**：任何编辑、拖动、改设置都会立刻落盘，不用担心"忘了保存"；
2. **兼容旧数据**：读取时会自动识别新旧两种数据格式；
3. **损坏自动备份**：如果数据文件损坏，会先备份成 `.bak` 再处理，**绝不直接覆盖**；
4. **空数据防覆盖**：一旦加载失败、内存里是空的，程序会跳过保存，避免把你的数据清空。

启动时，程序只会恢复**上次处于打开状态**的那些便签和清单，其余安静地留在管理界面里，随时可开。

---

## 九、结语

总结一下，这个工具体现了三个设计取向：

- **轻**：不联网、不要账号，打开就是一张便签，闭上就是托盘里的一个图标；
- **自由**：每张便签、每份清单都能独立定制外观和显示行为，默认值与已创建内容互不影响；
- **可靠**：实时保存、损坏备份、空数据保护，让你放心地把碎片想法交给它。

如果你希望桌面既清爽又不丢事——**便利贴负责"记下来"，任务清单负责"做下去"，管理界面负责"找得到"**——那它就是为你准备的。
